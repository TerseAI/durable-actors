---

Durable Actors provides TypeScript and Python SDKs with a Rust runtime for shared, persistent state. Each actor keeps its state across restarts and runs methods one at a time by default.

## Languages

[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)](sdk/README.md) [![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)](sdk-python/README.md)

```text
Go to https://github.com/TerseAI/durable-actors, follow the README for my language and build a sample project. Get the development server running and ask me where I would like to invoke my actors from.
```
