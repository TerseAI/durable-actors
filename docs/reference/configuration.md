# Configuration

| Variable                                | Default                                            | Description                                                                                                                                                                                                             |
| --------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DURABLE_OBJECT_API_KEY`                | Required locally and for hosting                   | Server API key for deployment and actor access. Remote clients use the same key. No surrounding whitespace. Also authenticates WebSocket callbacks.                                                                     |
| `DURABLE_OBJECT_CONTROL_PLANE_URL`      | SDK: `http://127.0.0.1:7100`; required for hosting | HTTP(S) server origin. SDK fallback: `http://127.0.0.1:7100`. A port and trailing slash are allowed; paths, queries, fragments, and user credentials are not. Hosted URLs must be reachable by clients and actor hosts. |
| `DURABLE_OBJECT_SOCKET_GATEWAY_URL`     | Control plane URL                                  | Separate HTTP(S) gateway origin for backend WebSocket connections, with the same origin restrictions.                                                                                                                   |
| `DURABLE_OBJECT_NAMESPACE_ID`           | Server-selected scope                              | Optional namespace override. Must satisfy the [identity rules](api.md#identity) and match a delegated token's scope.                                                                                                    |
| `DURABLE_OBJECT_TOKEN`                  | Unset                                              | Delegated session token instead of an API key. Configure exactly one credential. The SDK does not renew session tokens.                                                                                                 |
| `DURABLE_OBJECT_POSTGRES_URL`           | Required for hosting                               | PostgreSQL connection URL for deployment configuration and public contracts. Ownership, leases, and state use the bucket. The database user must be able to run migrations.                                             |
| `GOOGLE_APPLICATION_CREDENTIALS`        | Google Application Default Credentials             | Path to a GCS service-account credentials file. Omit when using an attached Google identity.                                                                                                                            |
| `DURABLE_OBJECT_SANDBOX_PROVIDER`       | Required for hosting                               | Cloud execution provider. Supported value: `modal`.                                                                                                                                                                     |
| `MODAL_TOKEN_ID`                        | Required for Modal                                 | Token ID for the workspace that owns the actor image. No surrounding whitespace.                                                                                                                                        |
| `MODAL_TOKEN_SECRET`                    | Required for Modal                                 | Token secret for that workspace. No surrounding whitespace.                                                                                                                                                             |
| `DURABLE_OBJECT_JWT_SIGNING_KEY`        | Generated locally; required for hosting            | Base64-encoded Ed25519 PKCS#8 signing key. Reuse after server restarts.                                                                                                                                                 |
| `DURABLE_OBJECT_JWT_KEY_ID`             | `primary`                                          | Signing key identifier.                                                                                                                                                                                                 |
| `DURABLE_OBJECT_JWT_ISSUER`             | `durable-object-control-plane`                     | Token issuer.                                                                                                                                                                                                           |
| `DURABLE_OBJECT_AUTHORITY_JWT_AUDIENCE` | `durable-object-authority`                         | Audience for server authentication.                                                                                                                                                                                     |
| `DURABLE_OBJECT_INVOKE_JWT_AUDIENCE`    | `durable-object-invoke`                            | Audience for actor calls.                                                                                                                                                                                               |
| `DURABLE_OBJECT_JWT_MAX_TTL_SECONDS`    | `86400`                                            | Positive maximum token lifetime in seconds. Session tokens are also capped at 24 hours.                                                                                                                                 |
| `DURABLE_OBJECT_CONTROL_PLANE_BIND`     | `127.0.0.1:7100`                                   | Server listening address. Use `0.0.0.0:7100` to accept connections through the container's published port.                                                                                                              |
| `DURABLE_OBJECT_PROCESS_ROLE`           | CLI: `control_plane`; native executable: `host`    | Set to `control_plane` for the hosted server. Providers launch actor hosts with `host`.                                                                                                                                 |
| `DURABLE_OBJECT_ACTOR_IDLE_TIMEOUT_MS`  | `60000`                                            | Idle time before an actor may hibernate. Range: 1–86400000 milliseconds.                                                                                                                                                |
| `DURABLE_OBJECT_HOST_IDLE_TIMEOUT_MS`   | `300000`                                           | Idle time before an unused cloud host may stop. Range: 1–86400000 milliseconds.                                                                                                                                         |
| `DURABLE_OBJECT_HOST_STARTUP_MS`        | `10000`                                            | Positive integer timeout in milliseconds for TypeScript actor-host startup.                                                                                                                                             |
| `DURABLE_OBJECT_SANDBOX_COMMAND`        | `little-actors-modal-go`                           | Provider executable. Override when supplying a custom runtime distribution.                                                                                                                                             |
| `DURABLE_OBJECT_SOCKET_EVENT_URL`       | Disabled                                           | HTTP(S) callback for successfully handled incoming WebSocket messages. See the [callback protocol](http.md#websocket-callbacks).                                                                                        |
| `DURABLE_OBJECT_BINARY`                 | Downloaded runtime                                 | Existing native executable, bypassing runtime downloads. Relative paths resolve from the working directory.                                                                                                             |
| `DURABLE_OBJECT_CACHE_DIR`              | `~/.cache/little-actors`                           | Downloaded runtime cache. Ignored when `DURABLE_OBJECT_BINARY` is set.                                                                                                                                                  |
| `DURABLE_OBJECT_TELEMETRY`              | Enabled                                            | Set to `0` to disable SDK invocation telemetry on standard error.                                                                                                                                                       |
| `RUST_LOG`                              | `info`                                             | Native runtime log filter, e.g. `warn` or `debug`.                                                                                                                                                                      |
| `DURABLE_OBJECT_BUCKET`                 | Required for hosting and local GCS                 | One bucket name, without `gs://`, for ownership, leases, and snapshots. See [object paths](../guides/replication.md#object-paths).                                                                                      |
| `DURABLE_OBJECT_REPLICA_REGIONS`        | `[]`                                               | JSON list of up to eight execution regions; duplicates allowed. Count is derived from this list. Empty uses object storage only.                                                                                        |
| `DURABLE_OBJECT_PROJECT`                | `.`                                                | Local actor project directory (`dev --project`).                                                                                                                                                                        |
| `DURABLE_OBJECT_ENTRYPOINT`             | `src/durable-objects.ts`                           | Local actor source file (`dev --entrypoint`).                                                                                                                                                                           |
| `DURABLE_OBJECT_PORT`                   | `7100`                                             | Local listening port (`dev --port`); `0` selects a free port.                                                                                                                                                           |
| `DURABLE_OBJECT_STORAGE`                | `local`                                            | Local file bucket or `gcs` (`dev --storage`).                                                                                                                                                                           |
| `DURABLE_OBJECT_DATA_DIR`               | `<project>/.little-actors`                         | Persistent local state directory (`dev --data-dir`).                                                                                                                                                                    |

Set the same API key on the local actor runtime and your backend. Configuration comes from environment variables or CLI flags; no connection configuration file is created or read. Explicit CLI flags override their environment variables.
