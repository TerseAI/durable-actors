# Configuration

Set `DURABLE_OBJECT_PROJECT_ID` to your actor project ID for `start --dev` and client commands. Use the same ID in your application backend. Plain `start` uses the hosted runtime settings below.

| Variable                                | Default                                            | Description                                                                                                                                                                                                             |
| --------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DURABLE_OBJECT_API_KEY`                | Read from `.env` or generated by `start --dev`             | Server API key for deployment and actor access. Remote clients use the same key. No surrounding whitespace. Also authenticates WebSocket callbacks.                                                                     |
| `DURABLE_OBJECT_CONTROL_PLANE_URL`      | SDK: `http://127.0.0.1:7100`; required for hosting | HTTP(S) server origin. SDK fallback: `http://127.0.0.1:7100`. A port and trailing slash are allowed; paths, queries, fragments, and user credentials are not. Hosted URLs must be reachable by clients and actor hosts. |
| `DURABLE_OBJECT_POSTGRES_URL`           | Required for hosting                               | PostgreSQL connection URL for deployment configuration, public contracts, and spare claims. Ownership, leases, and state use the bucket. The database user must be able to run migrations.                                             |
| `GOOGLE_APPLICATION_CREDENTIALS`        | Google Application Default Credentials             | Path to a GCS service-account credentials file. Omit when using an attached Google identity.                                                                                                                            |
| `DURABLE_OBJECT_SANDBOX_PROVIDER`       | Required for hosting                               | Cloud execution provider. Supported value: `modal`.                                                                                                                                                                     |
| `DURABLE_OBJECT_RUNTIME_IMAGE` | Required for Modal | Published shared runtime image ID (`im-...`) containing the matching Rust, Bun, and SDK. Used for actor and replica sandboxes; deployment requests supply the customer build image separately. |
| `MODAL_TOKEN_ID`                        | Required for Modal                                 | Token ID for the workspace that owns the runtime image and code snapshots. No surrounding whitespace.                                                                                                                                        |
| `MODAL_TOKEN_SECRET`                    | Required for Modal                                 | Token secret for that workspace. No surrounding whitespace.                                                                                                                                                             |
| `DURABLE_OBJECT_JWT_SIGNING_KEY`        | Generated locally; required for hosting            | Base64-encoded Ed25519 PKCS#8 signing key. Reuse after server restarts.                                                                                                                                                 |
| `DURABLE_OBJECT_JWT_KEY_ID`             | `primary`                                          | Signing key identifier.                                                                                                                                                                                                 |
| `DURABLE_OBJECT_JWT_ISSUER`             | `durable-object-control-plane`                     | Token issuer.                                                                                                                                                                                                           |
| `DURABLE_OBJECT_AUTHORITY_JWT_AUDIENCE` | `durable-object-authority`                         | Audience for server authentication.                                                                                                                                                                                     |
| `DURABLE_OBJECT_INVOKE_JWT_AUDIENCE`    | `durable-object-invoke`                            | Audience for actor calls.                                                                                                                                                                                               |
| `DURABLE_OBJECT_SOCKET_JWT_AUDIENCE`    | `durable-object-authority:websocket`               | Host socket-ticket audience. Providers derive it from the authority audience plus `:websocket`; manual hosts must use the matching value.                                                                               |
| `DURABLE_OBJECT_JWT_MAX_TTL_SECONDS`    | `86400`                                            | Positive maximum lifetime for internal host and actor connection credentials, in seconds.                                                                                                                               |
| `DURABLE_OBJECT_CONTROL_PLANE_BIND`     | `127.0.0.1:7100`                                   | Server listening address. Use `0.0.0.0:7100` to accept connections through the container's published port.                                                                                                              |
| `DURABLE_OBJECT_PROCESS_ROLE`           | CLI: `control_plane`; native executable: `host`    | Set to `control_plane` for the hosted server. Modal launches neutral sandboxes with `spare`; local development uses `host`.                                                                                                                                 |
| `DURABLE_OBJECT_ACTOR_IDLE_TIMEOUT_SECONDS` | `60`                                            | Idle time before an actor may hibernate, in both local and hosted runtimes. Range: 1–86400 whole seconds; use `10` for ten seconds.                                                                                                                                                |
| `DURABLE_OBJECT_HOST_IDLE_TIMEOUT_MS`   | `300000`                                           | Idle time before an unused cloud host may stop. Range: 1–86400000 milliseconds.                                                                                                                                         |
| `DURABLE_OBJECT_HOST_STARTUP_MS`        | `10000`                                            | Positive integer timeout in milliseconds for TypeScript actor-host startup.                                                                                                                                             |
| `DURABLE_OBJECT_SANDBOX_COMMAND`        | `little-actors-modal-go`                           | Provider executable. Override when supplying a custom runtime distribution.                                                                                                                                             |
| `DURABLE_OBJECT_SPARE_IDLE` | `5` | Ready idle sandboxes per role (actor or replica), runtime image, region, and resource configuration; 0–32. Zero creates sandboxes on demand and retires idle spares; assigned replicas remain until safely replaced or recovered. Controllers sharing PostgreSQL must use the same pool settings. Named Modal secrets bypass the actor pool. |
| `DURABLE_OBJECT_SPARE_REGIONS` | `north-america-east` | Comma-separated canonical regions for actor spares. Replica spares use `DURABLE_OBJECT_REPLICA_REGIONS`. |
| `DURABLE_OBJECT_SPARE_TTL_SECONDS` | `600` | Maximum unassigned idle lifetime; 30–3600 seconds. |
| `DURABLE_OBJECT_HOST_CPU_MILLIS` | `1000` | Actor sandbox CPU request and hard cap enforced by Modal; 100–64000 millicores. Replica sandboxes use 1000 millicores. |
| `DURABLE_OBJECT_HOST_MEMORY_MIB` | `1024` | Actor sandbox memory request and hard cap enforced by Modal; 128–262144 MiB. Replica sandboxes use 1024 MiB. |
| `DURABLE_OBJECT_SOCKET_EVENT_URL`       | Disabled                                           | HTTP(S) callback for successfully handled incoming WebSocket messages. See the [callback protocol](../guides/websockets.md#websocket-callbacks).                                                                                        |
| `DURABLE_OBJECT_BINARY`                 | Downloaded runtime                                 | Existing native executable, bypassing runtime downloads. Relative paths resolve from the working directory.                                                                                                             |
| `DURABLE_OBJECT_CACHE_DIR`              | `~/.cache/little-actors`                           | Downloaded runtime cache. Ignored when `DURABLE_OBJECT_BINARY` is set.                                                                                                                                                  |
| `DURABLE_OBJECT_TELEMETRY`              | Enabled                                            | Set to `0` to disable SDK invocation telemetry on standard error.                                                                                                                                                       |
| `RUST_LOG`                              | `info`                                             | Native runtime log filter, e.g. `warn` or `debug`.                                                                                                                                                                      |
| `DURABLE_OBJECT_BUCKET`                 | Required for hosting and local GCS                 | One bucket name, without `gs://`, for ownership, leases, and snapshots. Object paths are defined in [storage_paths.rs](../../src/storage_paths.rs).                                                                                      |
| `DURABLE_OBJECT_REPLICA_REGIONS`        | `[]`                                               | JSON list of up to eight execution regions; duplicates allowed. Count is derived from this list. Empty uses object storage only.                                                                                        |
| `DURABLE_OBJECT_PROJECT`                | `.`                                                | Local actor project directory (`start --dev --project`).                                                                                                                                                                        |
| `DURABLE_OBJECT_ENTRYPOINT`             | `src/durable-objects.ts`                           | Local actor source file (`start --dev --entrypoint`).                                                                                                                                                                           |
| `DURABLE_OBJECT_PORT`                   | `7100`                                             | Local listening port (`start --dev --port`); `0` selects a free port.                                                                                                                                                           |
| `DURABLE_OBJECT_STORAGE`                | `local`                                            | Local file bucket or `gcs` (`start --dev --storage`).                                                                                                                                                                           |
| `DURABLE_OBJECT_DATA_DIR`               | `<project>/.little-actors`                         | Persistent local state directory (`start --dev --data-dir`).                                                                                                                                                                    |
| `DURABLE_OBJECT_REGION`                 | Unset                                              | Default region for new actors when `homeRegion` is omitted. Explicit assignments must match this region; existing actors retain their saved home.                                                            |
| `DURABLE_OBJECT_HOME_REGION`            | Unset                                              | Optional trusted backend assignment sent by the SDK in setup requests. Omit to use an existing actor's saved home or the control plane's default for a new actor.                                                     |
| `NGROK_AUTH_TOKEN` | Saved ngrok credentials | Authentication for the local [tunnel helper](../guides/local-development.md#test-modal-hosts-against-a-local-control-plane). Falls back to `NGROK_AUTHTOKEN`. |
| `NGROK_DOMAIN` | Assigned by ngrok | Optional fixed domain for the local tunnel helper. Falls back to `NGROK_URL`. |
| `NGROK_AUTHTOKEN` | Unset | Fallback for `NGROK_AUTH_TOKEN`. |
| `NGROK_URL` | Unset | Fallback for `NGROK_DOMAIN`. |

When `start --dev` generates a local key, set the printed environment variable in your backend terminal. Explicit CLI flags override their environment variables; no connection file is written.
